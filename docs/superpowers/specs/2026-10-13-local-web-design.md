# LumaBox 0.2 本地网页设计

用户已选择先做本地网页，最终目标仍为个人使用的 Linux 下载网站。本阶段交付可运行的本地版本；沿用现有会话原目录实施方式，使用 `feat/local-web` 分支。实际推送继续最后由用户确认。

## 目标和流程

单用户通过本机浏览器登录，粘贴单条抖音链接或分享文案、确认下载授权、提交任务、查看状态、领取 MP4 或整组图片 ZIP。网页使用既有下载内核，不能以任务提交成功代替文件下载成功。Windows 本地默认有界面，允许启动参数 `--headless`；此前无头测试仅在 DNS 阶段失败，无头及 Linux 成功不在本阶段虚报。

首版不增加标题/作者/封面解析、批量主页、重新编码或图片格式转换。页面响应式布局，以浅米色、橙色和绿色表达“光匣”，使用本地静态资产，不依赖第三方字体/CDN。

## 组件和接口

- FastAPI 提供同源静态网页和受保护 API，SQLite 保存任务及产物引用。
- 独立串行 worker 线程管理 CLI 子进程；无 shell，命令使用当前 Python 与 `-m lumabox`。一次一个运行任务，最多 10 个等待任务，单任务总期限 900 秒。
- 工作进程读取有界最终 JSON，要求 CLI 退出 0、success、已解析、完整解码及期望/实际数量一致；还须核对目录、文件名、非空大小及哈希，才将任务标为成功。
- 输入仅调用已有 `parse_input`；Web 保存规范化作品/短链地址，不保存分享文案或跟踪查询。下载输出路径由服务端 UUID 生成，客户端不能指定磁盘路径。
- 默认数据目录 `WebData/`，包含 SQLite 和私有产物目录；不静态挂载媒体目录。`file_id` 对应已完成任务的相对路径，API 不返回本机绝对路径、媒体签名地址、原始 CLI 输出或 Cookie。

API：`POST /api/login`、`POST /api/logout`、`GET /api/session`、`POST /api/jobs`、`GET /api/jobs`、`GET /api/jobs/{job_id}`、`GET /api/files/{file_id}`。登录后文件下载和任务查询均需要会话。任务状态为 pending/running/success/failed/expired，列表最多返回最近 30 条；成功后提供编号图片和 ZIP 的引用。

## 本地访问和会话

- 启动命令 `python -m lumabox.web` 或 `lumabox-web`，固定监听 `127.0.0.1`，默认端口 8765，不开放任意 host、reload 或多个服务 worker 参数。
- 密码来自 `LUMABOX_WEB_PASSWORD` 或启动时隐藏输入，至少 12 字符；无默认密码，不把密码写入日志、命令参数或数据库。服务仅保存加盐 PBKDF2 验证值。
- 会话随机生成，Cookie 为 HttpOnly、SameSite=Strict，最长 8 小时；每次启动会话失效。退出注销服务器端会话。
- 写操作检查当前本地 Origin 和会话 CSRF；登录要求同源 JSON。Host 只允许本地两个名称及当前端口，阻止 DNS rebinding 和跨站请求。
- 登录失败限制为每分钟 5 次；JSON 请求体最大 8 KiB、输入最大 4096 字符。返回固定错误码和中文提示，异常内容不直接外传。

## 存储、重启和关闭

SQLite 任务历史在服务重启后保留；启动将遗留 running 标为 failed/INTERRUPTED，pending 恢复执行。该版本仅支持一个服务实例占用数据目录，用实例文件锁拒绝重复启动。

产物保留 24 小时，worker 每分钟清理过期任务所属目录并标为 expired。全局产物容量 2 GiB，每次开始下载前预留 512 MiB，并检查磁盘空闲空间。失败仅清理本次服务生成的 UUID 目录。删除前确认真实路径处于私有产物根目录；符号链接不得用于文件下载或清理越界。

关闭服务时停止领取新任务，向当前 CLI 发中断信号，有界等待后终止；待子进程结束后清理本次目录和记录中断。原 CLI 的 Windows 10054 回调不在本阶段宣称修复，子进程 stderr 不进入页面。

## 验证与交付

离线测试覆盖队列和持久化、容量/期限/关闭、畸形 CLI 成功报告、文件越界/符号链接、未登录访问、跨站与 CSRF、登录限流、JSON 大小、真实 HTTP 和 Chromium 网页流程。子进程测试使用新生成媒体/受控本地脚本，不默认访问抖音。

真实 Chromium 检查桌面和移动宽度、登录/退出、提交/轮询、成功文件下载及失败提示；用现有授权样本实际网页下载需在可用网络验证，合成成功不能替代真实抖音。交付包含安装/启动指令、截图、测试及已验证/未验证记录，保留本地提交，推送待确认。
