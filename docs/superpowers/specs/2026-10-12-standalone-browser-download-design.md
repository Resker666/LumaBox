# LumaBox · 光匣：独立浏览器下载内核设计

日期：2026-10-12（Asia/Shanghai）

## 已批准的方向

新建精简仓库，不在 Resker666/douyin-downloader 的完整架构上继续开发。原项目保留为源码及边界情况参考。最终用途沿用原任务书：个人使用的 Linux 下载网站，输入抖音链接，下载授权的视频或一条图文作品的图片集合。

项目名称为 **LumaBox · 光匣**，仓库目录、Python 包及命令行入口统一使用 `lumabox`。

当前阶段只交付独立下载内核与命令行。网页、API、鉴权、队列、清理及 Docker 部署放在内核真实实验通过后的独立阶段。仓库本地路径为 `E:\develop\douyin-downloader\lumabox`；不创建远程仓库、不推送、不部署。

## 已有证据与未解决的问题

- 普通 HTTP 分享页实验对视频 7686430330920075249 失败：200 HTML 中没有预期嵌入数据。
- Codex 内置浏览器未登录账号可以播放该视频，并下载到 1920×1080、124.6 秒的 H.264/AAC MP4，完整解码通过。
- 同一浏览器下载图文作品 7695689642767235187 的全部 12 张 JPEG，数量、尺寸、唯一性与逐张解码检查通过。
- 成功下载目前由 Codex 浏览器交互工具完成。普通 Playwright、无头运行及云服务器网络尚未验证。

首要任务是验证独立程序能复现这些结果，不能把交互工具成功直接算作程序实现成功。

## 方案与范围

采用 Python 3.11+ 和 Playwright 的标准 Chromium。测试用 pytest、pytest-asyncio；媒体检查使用系统 FFmpeg/FFprobe。普通浏览器实际加载作品页面，读取页面中已提供的资源；不移植原项目的 API 签名、桌面桥接或批量下载器。

第一版支持：

1. 完整 `/video/<id>`、`/note/<id>` 链接；`v.douyin.com` 短链；分享文案中仅包含一条受支持链接。
2. 普通未登录浏览器会话。默认有界面运行便于观察；提供无头选项，但以实测结果报告支持情况。
3. 视频输出 MP4；图集按作品轮播顺序输出编号图片和 ZIP；每次运行产生单独目录及脱敏 JSON 结果。
4. 最多一个作品在执行，不做作者主页、合集、收藏、直播或批量列表；不导入账号 Cookie，不自动登录。

## 数据流程及模块

`输入校验 → 浏览器正常导航/短链解析 → 作品识别与资源等待 → 候选媒体提取 → 有界下载 → 完整媒体验证 → 发布产物/结果`

- `urls.py`：从分享文案提取单一链接，校验协议、精确域名、端口、用户名、控制字符、作品路径；解析最终作品 ID。
- `browser.py`：管理单次 Chromium 会话，控制导航和等待时间，识别明确登录要求、挑战、访问拒绝及资源缺失。仅使用正常浏览器配置，不设置隐藏自动化标记或破解签名。
- `extract.py`：从当前作品页面 DOM 提取视频或轮播图片候选及顺序。使用作品区域和轮播结构，不能只凭随机 CSS 类名、所有 img 的出现顺序或媒体尺寸来认定目标。验证 ID 与最终作品页面一致；排除头像、推荐视频、二维码、封面及背景副本。
- `transfer.py`：下载浏览器提供的 HTTPS 媒体资源，保留同一匿名会话；实施域名、地址、重定向及大小校验，不把完整媒体签名 URL 写入日志或结果。
- `verify.py`：调用 FFprobe 及 FFmpeg，验证非空文件、格式、视频/音频完整解码或每张图片完整解码；收集尺寸、时长、字节数和 SHA-256。
- `cli.py`：参数解析、结果输出、清理失败产物、退出状态。Python 包入口允许脱离 Codex 调用。

资源提取必须基于实际观察到的 DOM 或正常页面请求；不能伪造接口请求或通过后台应用状态读取账号秘密。若 video 暂时为 blob，允许在规定时限内等待页面自然提供 HTTPS 资源；不能直接将 blob 当成服务器可用 URL，不能取得受支持资源时明确失败。

## 网络和资源边界

- 页面只允许 `douyin.com`、`www.douyin.com`、`v.douyin.com`、`iesdouyin.com`、`www.iesdouyin.com`，只允许 HTTPS 默认端口。短链重定向仅可到上述允许页面域名，重定向最多 5 次。
- 初始媒体允许经本次实验确认的 `douyinvod.com`、`douyinpic.com` 根域及其子域，使用严格域名边界匹配；新 CDN 域名必须取得实际证据后增加。
- 所有导航及媒体请求均阻止本机、私网、保留或非公网目的地址，不放宽校验来适配当前 VPN 的私有 DNS 映射。不允许由用户指定任意媒体 URL。
- 导航超时 30 秒，页面资源等待上限 45 秒；媒体连接/响应空闲超时 15 秒，单文件下载总时限 180 秒；重定向校验逐跳执行。
- 单视频最多 100 MiB；单图片最多 20 MiB；单图集最多 50 张、总计 200 MiB。数量或文件超过上限明确失败，不保存半组为成功。
- 文件名由作品 ID、运行 ID 和序号产生，禁止使用用户输入的磁盘路径片段；下载目录由本地 CLI 操作者指定，未来 Web API 不接受客户端磁盘路径。
- 对明确 401、403、429、验证码、挑战页或强制登录停止本次实验；普通可关闭的登录推广弹窗不自动等同于强制登录。不能输入账号、解验证码、重试规避或跳转到其他接口尝试突破限制。

## 结果与成功判定

脱敏结果至少包括：作品 ID、类型、解析状态、期望文件数、实际文件数、实际文件名、字节数、媒体检查结果、错误类型。HTTP 状态仅在实际观察到时记录，不推测；不记录 Cookie、鉴权头、完整签名媒体地址、原始页面正文或验证令牌。

- 视频成功：取得与当前作品匹配的非空 MP4，存在视频流，完整音视频解码通过。播放页面加载成功不算下载成功。
- 图集成功：取得页面确认的全部图片，保持作品顺序，每张文件完整解码。图片不能去重后悄悄改变作品数量；对背景副本进行候选层去重，真实作品中有重复图片仍须按作品序号保留。
- 所有产物先写到本次运行的临时目录；验证通过后发布。失败删除本次临时产物，保留脱敏错误报告，不影响之前成功的文件。
- CLI 全部文件成功时退出 0；下载、解析或验证失败时退出非零。错误包括 INVALID_INPUT、AUTH_REQUIRED、BLOCKED、CHALLENGE_REQUIRED、RATE_LIMITED、NOT_FOUND、UNSUPPORTED_MEDIA、RESOURCE_TIMEOUT、UNSAFE_TARGET、SIZE_LIMIT、DOWNLOAD_FAILED、VERIFY_FAILED。

## 复用和许可

第一阶段不直接复制原仓库业务模块，避免把日志、配置、Cookie、数据库、批量模式等依赖带入。可参考 URL/文件名测试案例、临时文件发布、超时和失败清理的经验；自行实现所需的小型模块。

若之后复制原仓库具体代码，必须记录原文件、来源提交 `9874f41`、适配目的及变化，保留 jiji262 的 MIT 版权与许可。当前设计不使用 aiaoxd/douyinDownloader 未确认许可的源码。

## 验证与交付

先用离线测试覆盖输入和重定向边界、作品与资源匹配、图片顺序及副本排除、挑战停止、容量上限、残留清理及验证失败。浏览器部分用本地合成作品页测试，联网案例独立运行，不作为普通测试的隐式网络请求。

真实验收使用已授权的视频 7686430330920075249 与图集 7695689642767235187，记录独立程序实际结果。目标机器仍为当前 Windows 电脑；如果 VPN 或访问策略阻止程序执行，形成诊断结果和用户可运行命令，不放宽校验、不虚报成功，不进入网页阶段。

交付包含可独立运行的 CLI、安装和测试说明、自动化测试及真实实验报告。未来网站阶段在独立内核复现成功后制定单独设计，并保留原任务书关于单用户鉴权、文件授权、限流、容量清理和 HTTPS 的要求。Linux 云服务器须单独复测。
