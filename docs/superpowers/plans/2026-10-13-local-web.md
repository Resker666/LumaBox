# LumaBox 本地网页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans in this session. Steps use checkbox syntax for tracking.

**Goal:** 交付个人使用的本地登录网页，通过现有 CLI 下载授权视频/图集并领取真实文件。

**Architecture:** FastAPI 静态页面和 JSON API；SQLite 持久任务；单 worker 管理独立 CLI 子进程和私有文件。CLI 输入、提取和下载策略沿用 0.1。

**Tech Stack:** Python 3.11+、FastAPI/Uvicorn、SQLite、Playwright、HTTPX、FFmpeg。

**Spec:** `docs/superpowers/specs/2026-10-13-local-web-design.md`。

## Global Constraints

- `feat/local-web` 本地实施，不改已推送 main，不推送或发布；使用现有原目录工作方式。
- 默认 127.0.0.1:8765，有界面；单用户密码至少 12 字符，隐藏提示或环境变量，8 小时会话。
- 1 个运行、10 个等待、任务 900 秒；JSON 8 KiB、输入 4096 字符、登录失败每分钟 5 次。
- 产物 24 小时，容量 2 GiB，启动任务预留 512 MiB；只清理自己的 UUID 子目录，拒绝链接越界。
- API 不输出绝对路径、Cookie、签名 URL或原始子进程日志；只有完整文件及报告一致才成功。
- 不修改 CLI 下载算法，不主动绕过访问限制、不重复当前 DNS 失败；Linux/无头真实成功单独验收。

## Review Focus

- CLI 返回 success 但文件缺失、哈希不符或目录越界：不得产生下载按钮（任务 1）。
- 服务第二实例/重启/关闭当前任务：防止重复下载与残留 running（任务 1）。
- 本地网页被恶意站点调用、Host 伪造、未登录取文件：拒绝请求（任务 2）。
- 图集文件、ZIP 双份占用及过期清理：容量计算包含实际文件，活动任务不被清理（任务 1/2）。
- 表单内容/失败原因含 HTML，移动宽度和反复轮询：不执行输入、保持可操作（任务 3）。

### Task 1: 持久任务、CLI worker 和私有文件

**Files:** `src/lumabox/web/{__init__,config,store,worker}.py`、`tests/test_web_jobs.py`。

**Interfaces:** `WebConfig(data_dir: Path, port=8765, headless=False)`；`JobStore(config)` 提供 create/claim/list/get/finish/fail/file/expire/recover；`JobWorker(config, store)` 提供 start/stop/run_once。任务 API 数据只含公开字段，产物以 file_id 和相对路径持久化。

- [ ] 写失败测试：队列 10 条满时拒绝、顺序领取、重启恢复、实际子进程成功/失败/超时、假成功/目录越界/哈希不符、24h 清理和容量边界。
- [ ] 跑 `pytest tests/test_web_jobs.py -q`，确认功能缺失失败。
- [ ] 实现 SQLite 事务和私有目录策略，串行 CLI 子进程，有界结果读取/关闭及实例锁；客户端不控制路径或 subprocess 命令。
- [ ] 同一命令通过后提交 `feat: persist and run local web download jobs`。

### Task 2: 认证、同源 API 与下载文件

**Files:** `src/lumabox/web/{auth,app}.py`、`tests/test_web_api.py`；`pyproject.toml` 添加 web/dev 测试依赖。

**Interfaces:** `create_app(config: WebConfig, password: str, worker: JobWorker | None = None) -> FastAPI`；消费 Task 1，启动/关闭 worker 由 lifespan 管理。任务接口及密码配置按 spec。

- [ ] 写失败测试：未登录 jobs/file 401、Origin/Host/CSRF 拒绝、退出和会话到期、5 次失败限流、8 KiB 请求体、合法任务、ID/文件越界、真实下载字节和报告脱敏。
- [ ] 跑 `pytest tests/test_web_api.py -q`，确认缺实现失败。
- [ ] 实现密码加盐验证、服务器会话、JSON/Origin/Host/CSRF及固定错误响应；下载仅查询 file_id 并验证根目录/非链接文件，保护完整文件接口。
- [ ] 同一命令通过后提交 `feat: protect local web jobs and file downloads`。

### Task 3: 光匣网页、启动入口和完整交付

**Files:** `src/lumabox/web/{__main__,static/index.html,static/app.css,static/app.js}`；`tests/test_web_ui.py`、README、CHANGELOG、验证记录。

**Interfaces:** 入口 `python -m lumabox.web [--port PORT] [--data PATH] [--headless]`；读取环境密码或 getpass 隐藏输入。前端调用 Task 2 同源接口，CSRF 仅驻留内存。

- [ ] 用真实 Chromium 写登录、分享文案提交、pending/running/success、文件下载、失败/退出以及桌面/手机宽度无溢出的失败测试。
- [ ] 跑 `pytest tests/test_web_ui.py -q`，确认界面/入口缺失失败。
- [ ] 实现响应式中文 UI、表单授权校验和串行轮询，使用 textContent 处理动态内容；提供单密码启动、可选无头和静态打包配置，忽略 WebData。
- [ ] 网页测试及完整套件通过；构建/CLI帮助/差异检查，独立全分支审查，修复重要发现并验证。记录截图和真实样本网络限制，提交 `feat: deliver LumaBox local web interface`。

执行沿用当前会话直接实现方式；用户已选择本地网页路线。所有实现先交付可审阅本地结果，实际推送另由用户确认。
