# LumaBox 0.3.0 · 本地下载工作台

0.3.0 根据实际网页试用反馈简化个人下载流程：粘贴抖音视频或图集链接即可开始，完成后文件已保存在本机 Output，可直接打开文件夹。

## 本版变化

- 去掉本地密码登录与逐次授权勾选；服务仍固定监听 127.0.0.1，保留同源、Host 与 CSRF 校验。
- 视频默认上限为 1 GiB，在网页可调整为 1～8192 MiB，浏览器记住设置，每个任务独立保存所用上限。
- 失败任务可一键重试；超限时显示可确认的文件大小或读取下限。
- 文件长期保留在 Output；主要操作为打开文件夹，另存 MP4、图片和 ZIP 保留为次要入口。
- 旧成功文件迁移时保留原件，校验原件及暂存副本哈希，失败时保留旧目录映射。
- 下载、解码和整任务等待预算延长，不限制视频自身时长。

## 启动

安装方式及所需 Python、Chromium、FFmpeg 依赖见 [README](../../README.md)。已安装环境在仓库目录执行：

```powershell
.\.venv\Scripts\python.exe -m lumabox.web
```

打开 http://127.0.0.1:8765/。单张图片上限仍为 20 MiB，图集最多 50 张、200 MiB；单任务最多 60 分钟。

## 验证边界

本版面向 Windows 个人本地使用。Linux、云服务器及无头真实下载尚未验收；部分网络或作品仍可能返回访问或地址校验错误。Windows 10054 关闭回调尚未宣称修复。图片保留网站提供的原始 JPEG/WebP 字节，没有转 JPG 或去水印处理。

本版材料位于 feat/local-web 分支；主分支合并和版本标签为后续发布步骤。
