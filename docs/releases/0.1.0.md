## 本版范围

独立 Python CLI，保存一条已授权抖音视频或完整图集。无需 Codex 浏览器工具，不读取现有浏览器登录资料。原 `Resker666/douyin-downloader` 仅作参考，未复制其业务代码。

需要 Python 3.11+、Playwright 1.58.0 对应的 Chromium，以及 PATH 中的 FFmpeg/FFprobe。安装、命令和错误说明见[README](../../README.md)，变更清单见[CHANGELOG](../../CHANGELOG.md)。
