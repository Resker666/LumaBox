# 取消下载与网络诊断验证

范围：在 0.4.0 日常体验版本上增加任务取消和可确认的网络失败原因，开发版本 0.4.1。VPN / 代理兼容只进入低优先级 TODO，本轮不改变目的地址检查，不支持暂停续传。

## 行为

- 等待任务立即变为 cancelled，不再被领取；运行任务先变为 cancelling，回收当前下载进程树并尝试清理该任务的未完成输出后，才变为 cancelled。清理失败沿用已有延后重试机制，页面不宣称文件必然已删除。
- cancelling 阻止下一任务领取和当前记录移除。取消与发布使用同一存储锁：取消先到则不发布；成功先到则拒绝取消并保留文件。取消可重复请求，已取消记录可重新下载、筛选、移除；重新下载从头开始。
- 工作进程轮询和文件哈希检查可响应取消；重启将中断中的取消意图保留为已取消。成功媒体不受取消操作影响。
- 新失败任务只保留固定网络原因、允许的阶段和有界域名：非公网 DNS、DNS 失败/超时、连接拒绝/重置/超时、网络不可达、TLS 失败和一般连接失败。网页不展示原始异常、签名地址、Cookie，不把未知网络失败归咎于 VPN。

## 测试过程

最初新增测试得到 14 项预期失败、1 项通过，网页测试得到 2 项预期失败；实现后 19 项通过，验证真实工作进程、临时文件、HTTP API 和 Chromium 网页。所有下载来源都是本地生成媒体或受控测试连接，不请求真实抖音。

首轮完整回归 347 项通过、2 项失败、1 项跳过。两项失败为 test_idle_timeout_removes_partial 和 test_cancel_interrupts_trickled_headers：旧测试严格期望诊断中不存在新增连接原因/提前记录的域名。按新的诊断约定补充预期字段，原有时限和清理断言保留。

独立审查与本地复现另确认三项边界问题：取消状态在清理前结束、已建立隧道的连接重置异常被 gather 丢弃、DNS 的外层超时被归为连接超时。三项专门回归均先失败，修补后相关测试 86 项通过、1 项跳过；独立复核确认三项问题均已解决。

最终完整回归：**352 项通过、1 项跳过、1 条已有 Starlette 弃用警告，223.86 秒**。跳过项需要 Windows 符号链接权限；相关 Windows junction 与进程树验证通过。报告保存在本地忽略目录 .superpowers/cancel-diagnostics/full-final.xml。

已将本机可编辑安装更新为 0.4.1，没有新增依赖。升级前再次确认无活动任务，仅停止核对过 PID、创建时间、完整命令和父进程的旧服务，再通过一键启动器启动 0.4.1。随后从另一个进程验证实际服务版本、新取消入口和 cancelled 筛选；9 条历史、16 条文件记录及对应文件大小均保留。验证未创建新的用户历史或请求抖音。

## 数据保留与证据边界

升级前已确认本机服务数据目录和输出目录均属于本项目；9 条历史（4 成功、5 失败）、16 条文件记录，没有活动下载。SQLite 备份位于 WebData/backups/before-cancel-diagnostics-bf0e4da4e8df4607bfc3105e8a8fb9bb.sqlite3，备份和实际媒体均从 Git 排除。

本轮验证的是取消控制与故障诊断，不将本地模拟连接作为新的真实抖音下载、VPN 兼容或 Linux 下载成功证据。此前用户已经确认 0.4.0 日常使用体验通过。
