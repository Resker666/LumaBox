# 单页动态照片下载验证

## 原始失败与确认依据

2026-10-16，云端两次提交短链 `https://v.douyin.com/PZRN8xhV6WU/` 均返回 `UNSUPPORTED_MEDIA`。该链接实际进入作品 `7696824302280965050` 的 `/note/` 页面。

隔离诊断重现 HTTP 200、作品区域身份已确认，但没有 `1/N` 计数器，原提取器返回 `Complete media count could not be confirmed`，尚未开始媒体传输。

实际 DOM 包含：

- 同一详情区域内的 `note_sidebar` 当前作品 ID。
- 一个与播放器视口吻合的水平轮播页，轨道只有该页，没有循环副本。
- `.xgplayer-progress.one-live-hide` 单项动态照片标志。
- 页内前景图片及一个独立的、具有普通 HTTPS 地址的动态片段播放器。
- 页外另有隐藏的背景音乐播放器，不能作为目标视频。

修复只接受上述已观察结构，仍拒绝没有完整页数证据的单个 DOM 图片、错位轮播、错误身份、缺失/冲突的动态播放器及不受支持的媒体地址。其他未知的无计数器布局仍会明确失败。

## 下载与文件语义

图集数量按图片页数计算，一页动态照片产生一个图片和一个对应的 `NN-motion.mp4`。所有文件均完整解码后才发布；任一片段失败会清理本次临时文件，不发布只有图片的成功结果。

动态片段使用任务的视频大小上限，同时计入图集整组 200 MiB 上限；图片仍为每张 20 MiB、最多 50 页。ZIP 包含全部图片、片段和脱敏报告。保留网页提供的字节，不合成背景音乐，不创建 Apple 原生 Live Photo 配对元数据。

网页按类型显示数量、提供混合预览及单独保存片段；切换或关闭预览会释放上一段媒体。解析失败只保留固定原因代码，短链已经确认的作品身份和标题仍可保存在历史中。
