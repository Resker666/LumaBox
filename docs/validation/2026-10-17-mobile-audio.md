# 0.6.0 手机界面与可选视频音频验证

日期：2026-10-17。用户选择方案 A：精简手机界面，保留默认视频 / 图集下载，音频默认关闭且可以补提取；图集配乐留待独立验证。本轮只更新本地开发和隔离验收服务，没有升级云服务器或推送 GitHub。

## 最终行为

- 手机首页依次显示输入框、进行中、最近收藏。进行中独立查询，不受历史搜索、筛选或分页影响；包含排队、下载、重试等待、取消和音频处理。
- 大标题和介绍在手机上收起；视频大小和“同时保存音频”位于默认折叠的下载选项。收藏卡保留标题、状态、时间 / 大小和预览 / 下载，技术信息及次要操作收在“更多”。文件管理位于顶部。
- 已有视频可以补生成 M4A。音频附在原收藏下，使用独立状态，不新增重复视频记录；失败或取消时保留视频。无音轨有明确提示。音频限额 200 MiB，处理期限 900 秒，接受请求时检查空间。
- AAC 音轨复制原数据包，其他支持的音轨转 AAC 192 kbit/s；通过 FFprobe 和完整音频解码，校验实际文件大小、时长及 SHA-256 后提供试听 / 下载。本版网页不抓取图集配乐。
- 复用既有单个 worker 串行执行，补提取不重新访问抖音。原下载重试保留音频选项；短链确认身份后发现重复作品时，可以转交音频请求至已有视频。

## 回归与审查

最终完整回归：**568 passed, 1 skipped, 1 warning，400.56 秒**。跳过项为 Windows 符号链接权限条件，实际 junction 边界测试已执行；警告是既有 Starlette TestClient / httpx 弃用提示。

新音频核心有 46 项针对性测试，覆盖 AAC 数据包复制、非 AAC 转码、无音轨、损坏输入、完整解码、大小限制、超时、取消、协议边界及文件替换。新增手机界面 17 项检查通过，包含两种浏览器的实际音频播放、下载、关闭释放，以及折叠选项校验、弹窗内错误、刷新时键盘焦点。

后端检查覆盖音频可选和严格布尔输入、已有视频补提取、判重、原任务重试、失败保留视频、取消 / 租约保护、空间刷新、重启恢复、损坏或丢失音频补生成、保存目录迁移及确认删除。

审查中发现并以失败回归复现后修复：损坏附件补生成丢失旧文件归属、中断音频在输出目录迁移后无法清理、仅凭文件名清理竞争文件、FFmpeg 重新打开临时路径可能覆盖硬链接源文件、最终文件在入库前被替换，以及手机折叠校验与弹窗错误提示问题。

最终音频创建清单只保存有界的相对路径与设备 / inode 身份，恢复和清理只处理身份匹配的未发布文件。FFmpeg 向保持打开的独占文件句柄输出，使用 `fd` 协议，不再以 `-y` 重新打开可替换的输出文件名。最终附件保持独占句柄至实际读回哈希检查和索引提交，入库前再次核对路径身份。源视频持有文件租约；音频活动期间禁止移除、删除或过期清理。

损坏或丢失的旧音频索引保留以供整组确认删除，公开文件列表只提供仍可读取且大小匹配的音频。音频清理暂时失败后会在重启重试；更改输出目录前先在原目录恢复中断产物。归属变化或无法安全清理时保留文件并提示失败。

0.6.0 wheel 已离线构建，41 个 Python / HTML / CSS / JS 文件与最终源码逐字节一致；安装包不包含媒体、数据库、私有凭据或本地环境。

本机真实播放结束后仍观察到已有的 asyncio `WinError 10054` 连接关闭回调输出。本轮两种浏览器的播放、拖动、下载与哈希检查均成功；没有将旧回调问题记为已修复。
