# 云端登录体验验证

开发版本 0.4.3，运行候选提交 4a0d045。用户要求优化现有云端登录界面，原入口为不可自定义外观的浏览器 Basic 认证弹窗。本次换成与光匣工作台一致的登录页面，保留同一访问密码，不增加账号注册或密码重置；默认本地版继续免登录。

## 交互与保护

桌面展示品牌文案与登录卡片，手机改为单列；访问密码支持显示/隐藏，提交时显示等待状态，错误在表单内反馈。只需密码，无需用户名。默认可记住登录最多 7 天，工作台提供退出登录。

可选 access-file 读取失败时拒绝启动；随机会话令牌使用 HttpOnly / SameSite=Strict Cookie，服务端保存令牌哈希及过期时间。重新登录旋转当前令牌，退出后旧令牌无法重放，5 次密码失败后短暂限流。服务重启要求重新登录；临时 HTTP 入口的传输限制保持不变，正式 HTTPS 配置启用 secure-cookie。

原有 Host、Origin、跨站 API、请求体和 CSRF 边界继续生效；未登录不能读取收藏、视频、图片、ZIP 或预览。密码不放进浏览器存储、HTML、日志或下载子进程参数；私有凭据与运行数据均从 Git 排除。

## 自动验证

新测试先观察匿名工作台仍直接返回 200 的失败，再实现登录保护；损坏 Unicode 密码先触发服务器异常，再修复为 400。12 项新增测试全部通过，包含真实 HTTP / Chromium 的表单、错误提示、密码切换、记住登录、文件下载、退出、手机布局，以及 API 的 Cookie 过期、旋转、注销、限流、请求边界和安全 Cookie。

完整项目回归：**366 项通过、1 项跳过、1 条已有警告，242.56 秒**。跳过项需要 Windows 符号链接权限；警告来自已有 Starlette / HTTPX 弃用提示。报告位于本地忽略目录 `.superpowers/cloud-deploy/login-full.xml`。

独立只读审查未发现 Critical / Important / Minor 问题；已明确接受临时 HTTP、服务重启后会话失效、单用户全局限流和不提供账号管理的范围限制。

## 云端更新与公网验收

更新前确认无活动任务，使用 SQLite backup API 备份历史，保留原密码并以 dev 持有的 0600 access.json 接入新登录。先保留旧 Nginx 认证、启用应用保护，实际验证回环匿名 API 为 401、正确密码可登录且 3 条历史及文件记录一致，再移除 Basic 认证。Nginx 语法校验通过后才重载；原 Ghost Chat 站点配置不变。

从本机 Chromium 通过真实公网 IP 完成：

- 首页跳转光匣登录页，页面与响应不再触发 WWW-Authenticate 原生弹窗。
- 原来的密码可以登录；会话 Cookie 为 HttpOnly，脚本不可读取。恢复浏览器 Cookie 状态后可直接回到工作台。
- 1440×960 桌面、390×844 手机均无横向溢出，手机主按钮在可视范围内；无页面脚本错误。
- 登录后下载原有真实 MP4，SHA-256 与此前样本相同；Range 预览返回 206，字节正确。
- 原有整组 ZIP 包含完整 12 张图片，各张哈希与报告一致。
- 退出后收藏和文件 API 均返回 401；伪造外部 Origin 的登录写入被拒绝。

公网验收证据位于本地忽略目录 `.superpowers/cloud-deploy/login-public.json`，桌面和手机截图位于 `Downloaded/login-validation/public-login-*.png`。测试未创建新用户历史或重新请求抖音作品；已下载文件和任务继续保留。域名 HTTPS 仍等待备案审核完成。
