# 本地体验改进验证

用户试用后明确要求：去掉本地密码和授权勾选，让大小限制可见、可调整，本地保存后直接打开文件夹，失败可重试。本版按这个已批准的方向修改现有流程，所有提交仍留在本地功能分支，推送由用户确认。

## 实现与初步证据

- 视频默认 1 GiB，1～8192 MiB 可调；CLI、下载内核和 Web 产物校验使用同一任务值。核心新行为先有 8 项失败，实现后 runner/CLI/transfer 合计 38 项通过。
- 默认 Output 永久保存；旧文件只复制、保留原始字节，启动先核对记录哈希，迁移在服务实例锁中进行。成功文件不再默认过期，失败临时文件仍清理。
- 本地无密码，但写操作仍验证准确同源 Origin 和自动 CSRF，拒绝跨站 API 读取及非法 Host。免密码/持久化/迁移/重试的新测试先有 23 项失败，随后 52 项通过、1 项因符号链接权限跳过。
- 原生打开文件夹只接受任务 ID，路径来自已完成任务并再次验证文件；不接受客户端磁盘路径，Windows 使用系统打开目录，其他环境有固定失败提示和另存后备入口。
- Chromium 页面先有 2 项旧登录/勾选行为导致失败；实现后 Web UI/API/jobs 共 57 项通过、1 项权限跳过，35.60 秒。覆盖桌面、手机、无密码/勾选、上限记忆、文件夹请求、另存 MP4/ZIP、大小详情与手动重试。
- 201 MiB 的 MP4 存储测试越过原 100/200 MiB 两层限制，通过发布及哈希核对；这不是 16 分钟真实视频下载证明。
- 单文件下载 1800 秒、视频完整解码 900 秒、Web 整任务 3600 秒；是处理期限，视频时长不限。慢解码预算另以边界测试和真实解码验证。
