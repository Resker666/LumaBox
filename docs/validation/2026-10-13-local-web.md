# 本地网页验证记录

## 范围

LumaBox 0.2.0，`feat/local-web`，Windows/Python 3.11.9。开发始于 2026-10-13，最终验证于 2026-10-14（北京时间）。复用 0.1 CLI 下载算法；新增 FastAPI/Uvicorn 本地工作台、SQLite、认证和任务 worker。网页依赖本次安装到项目虚拟环境：FastAPI 0.143.0、Uvicorn 0.54.0、HTTPX 0.28.1、Starlette 1.8.0。

## 已完成证据

- 开发前完整基线：179 项通过，93.97 秒。
- 任务层：缺少模块的失败测试后实现；17 项通过、1 项因 Windows 无符号链接权限跳过。覆盖真实 SQLite/子进程、排队、重启恢复、超时/关闭、伪成功、文件缺失、目录越界、哈希、ZIP 报告脱敏、容量和过期。
- 认证/API：缺少 app 模块的失败测试后实现；与任务层合计 37 项通过、1 项跳过，14.48 秒。验证登录/退出/过期、5 次失败限流、同源/Host/CSRF、流式及普通请求体限制、非法/未授权输入、私有文件及真实下载字节。
- 网页：首次因静态页面及启动入口缺失 3 项失败，实现后真实 Chromium 3 项通过，12.07 秒。覆盖桌面 1440×1000、手机 390×844、状态轮询、HTML 分享文案、登录/退出、失败原因、MP4 及 ZIP 下载、无水平溢出。下载后字节与新生成媒体一致；图集 ZIP 重新打开核对图片。
- 页面截图已人工检查，位于本机 `Downloaded/web-validation/login-desktop.png`、`tasks-desktop.png`、`tasks-mobile.png`，未纳入 Git。图中的小尺寸媒体来自测试，不能当作真实抖音成功证据。

- 首次最终完整套件：219 项通过、1 项因 Windows 符号链接权限跳过，119.67 秒。TestClient 使用 HTTPX 的上游弃用提醒 1 条，不影响通过。
- 构建 0.2.0 wheel，核对全部 Python 源文件、3 个静态资产的原始字节、CRC、两个启动入口；将 wheel 解包到独立目录，在现有虚拟环境依赖下从该布局导入，网页及 CSS/JS HTTP 响应均正常。这不是干净 Linux 安装实测。
- 独立分支只读审查发现清理线程退出、父进程退出后遗留后代、ZIP 三份副本峰值 3 项 Important，以及固定错误码丢失。执行者将误导重试的错误码归类为需要修补，并处理成功发布后的辅助日志删除问题。
- 新增回归测试先实际得到 9 个失败：文件租用缺失、清理异常导致终态缺失、已发布文件被删除、旧 ZIP 仍占临时空间、错误码丢失及进程树功能缺失。修补后通过：下载租用在传输结束前延迟清理；删除失败记录固定提示并重试；成功发布为最后一步；ZIP 验证后先移除旧归档再重建；保留两个固定错误码。
- Windows 下载进程在暂停状态加入专属 Job Object 后恢复，禁止后代脱离；停止时核对进程对象退出和整个 Job 无活动进程。真实子、孙进程忽略中断及父进程先退出两种情况均通过；真实 Chromium 在此 Job 中启动和渲染通过。Windows junction 越界拒绝、目标不被删除的测试也通过，无需符号链接权限。
- 最大图集存储测试使用 200 MiB 的受控存储数据，并先占用 1.5 GiB 逻辑文件大小，实测 ZIP 重写的每一步大小总和均低于 2 GiB；测试结束立即删除自建大文件。此数据用于容量测试，不作为媒体解码或真实下载证据。
- 最终完整套件：**231 项通过、1 项符号链接权限跳过、1 条上游 TestClient 弃用提醒，126.81 秒**。审查修补后重新构建 wheel（52,391 字节），全部源码、静态资产、入口及解包布局 HTTP 冒烟核对通过。
- 真实模块启动入口也已临时启动本地 HTTP 服务，验证登录、CSS、任务列表、退出和退出后 401；未提交抖音下载任务，测试服务已停止，测试密码未出现在日志。两个安装入口帮助信息正常。

## 审查中的验收决定

1. 真实抖音网页下载仍在正常网络单独验收：离线测试无法证明远端可访问；尚不能保证网页真实样本成功。
2. Linux/无头成功仍单独验收：Windows 本地证据无法证明服务器网络和浏览器模式；尚不能保证服务器成功。
3. 原 10054 回调不包含在网页修补声明中：CLI 曾在该回调出现时成功；命令行日志仍可能保留提示。

独立审查的初始结论为 With fixes；后续修补由回归 RED→GREEN 和完整测试验证，没有再次派发审查。

## 未验证及下一步

本阶段没有更改 DNS/VPN，也未重复此前非公网 DNS 失败。已有真实抖音成功来自 0.1 正常网络默认有界面 CLI：视频 7686430330920075249，1920×1080、124.6 秒、3,316,797 字节；图集 7695689642767235187，12/12 张、3,303,822 字节。这不能代替 0.2 网页入口的真实网络验收。

用户在正常网络启动 `python -m lumabox.web`，从网页提交相同视频及短链图集，领取并播放/打开产物。确认两个样本后再验证其他作品与目标 Linux 网络；无头此前只在 DNS 阶段失败，不据此断言浏览器模式本身不可用。

Windows 10054 回调问题仍未修复。CLI 子进程 stderr 不进入网页，页面不把日志干扰当作成功或失败的依据。
