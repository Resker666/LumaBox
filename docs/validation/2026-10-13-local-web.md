# 本地网页验证记录

## 范围

LumaBox 0.2.0，`feat/local-web`，Windows/Python 3.11.9。复用 0.1 CLI 下载算法；新增 FastAPI/Uvicorn 本地工作台、SQLite、认证和任务 worker。网页依赖本次安装到项目虚拟环境：FastAPI 0.143.0、Uvicorn 0.54.0、HTTPX 0.28.1、Starlette 1.8.0。

## 已完成证据

- 开发前完整基线：179 项通过，93.97 秒。
- 任务层：缺少模块的失败测试后实现；17 项通过、1 项因 Windows 无符号链接权限跳过。覆盖真实 SQLite/子进程、排队、重启恢复、超时/关闭、伪成功、文件缺失、目录越界、哈希、ZIP 报告脱敏、容量和过期。
- 认证/API：缺少 app 模块的失败测试后实现；与任务层合计 37 项通过、1 项跳过，14.48 秒。验证登录/退出/过期、5 次失败限流、同源/Host/CSRF、流式及普通请求体限制、非法/未授权输入、私有文件及真实下载字节。
- 网页：首次因静态页面及启动入口缺失 3 项失败，实现后真实 Chromium 3 项通过，12.07 秒。覆盖桌面 1440×1000、手机 390×844、状态轮询、HTML 分享文案、登录/退出、失败原因、MP4 及 ZIP 下载、无水平溢出。下载后字节与新生成媒体一致；图集 ZIP 重新打开核对图片。
- 页面截图已人工检查，位于本机 `Downloaded/web-validation/login-desktop.png`、`tasks-desktop.png`、`tasks-mobile.png`，未纳入 Git。图中的小尺寸媒体来自测试，不能当作真实抖音成功证据。

- 首次最终完整套件：219 项通过、1 项因 Windows 符号链接权限跳过，119.67 秒。TestClient 使用 HTTPX 的上游弃用提醒 1 条，不影响通过。
- 构建 0.2.0 wheel，核对全部 Python 源文件、3 个静态资产的原始字节、CRC、两个启动入口；将 wheel 解包到独立目录，在现有虚拟环境依赖下从该布局导入，网页及 CSS/JS HTTP 响应均正常。这不是干净 Linux 安装实测。
- 独立分支审查待完成；修补及最终结果在交付时补充。

## 未验证及下一步

本阶段没有更改 DNS/VPN，也未重复此前非公网 DNS 失败。已有真实抖音成功来自 0.1 正常网络默认有界面 CLI：视频 7686430330920075249，1920×1080、124.6 秒、3,316,797 字节；图集 7695689642767235187，12/12 张、3,303,822 字节。这不能代替 0.2 网页入口的真实网络验收。

用户在正常网络启动 `python -m lumabox.web`，从网页提交相同视频及短链图集，领取并播放/打开产物。确认两个样本后再验证其他作品与目标 Linux 网络；无头此前只在 DNS 阶段失败，不据此断言浏览器模式本身不可用。

Windows 10054 回调问题仍未修复。CLI 子进程 stderr 不进入网页，页面不把日志干扰当作成功或失败的依据。
