## 失败原因及修复

云端 0.4.5 在北京时间 13:59 收到短链 `https://v.douyin.com/puO92iLnceU/`，实际跳转至图文作品 `7697415943497351346`。失败原因是 `UNSUPPORTED_MEDIA / MEDIA_COUNT_UNCONFIRMED`，未进入文件传输。

隔离浏览器复现时已确认目标作品身份及播放器区域，正常等待 45 秒后仍没有数字页码，只有一张静态前景图片、无图片内动态视频。该页也没有既有单页 Live Photo 的 `one-live-hide` 标志，因此旧解析器保持 count=0 并拒绝发布。

实际页面存在独立的图片进度结构：`xg-progress.xgplayer-progress[data-index="0"]` 下的 `xg-outer.picture > xg-inners.progress-list` 只有一个 `xg-inner.picture-inner` 段。本版仅在作品身份已确认、唯一播放器 / 进度控制、首项标志、单项图片进度、唯一静态画面及现有轮播几何检查均一致时，用它确认单图完整性。不会仅根据加载了一张 DOM 图片推断总数。

多项进度、缺失 / 无关 / 歧义控制、非首项索引、额外画面、身份不符及图片内视频均不会走该静态兜底。带 `one-live-hide` 的作品仍必须具备图片内的动态片段，不能在视频未加载时保存成纯静态成功。图片外的背景音乐播放器不作为动态片段，也不合成为 MP4。
